----------------------------------------------------
Hi everyone! I built this application to learn how to program. It’s far from perfect.
I recently learned that .NET isn't exactly the fastest or most lightweight platform for running console applications
**(CLI).** However, I’m working on testing AOT; from what I’ve gathered, this compiles C# .NET code into a binary—
or something similar—allowing it to run "natively" on the machine.

For now, the menu is only in Spanish, but I hope to add a menu translation feature in future versions.

Anyway, I want to migrate this project to Rust and improve both the aesthetics and functionality. Stay tuned. Thanks for stopping by!
